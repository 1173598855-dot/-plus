# 工作台布局与前端优化设计

## 目标

在不改变任务领域规则、持久化方式和现有工作流的前提下，提高个人任务管理库在桌面与移动端的工作效率、信息扫描速度和视觉完成度。

本轮成功标准：

- 桌面首屏把主要空间留给看板或列表，不再被完整新建表单、纵向筛选器和常驻详情面板持续挤压。
- 新建、筛选和详情仍可快速访问，原有快捷键、导入导出、拖拽、批量操作和实时编辑行为保持不变。
- 移动端从上到下形成清晰的操作顺序，不出现控件重叠、横向页面滚动或过长的常驻表单。
- 界面仍是克制、可靠、专注的个人工作台，不转向营销页或装饰性仪表盘。

## 设计方向

采用“工作效率优先”的渐进披露布局：高频入口常驻，低频字段按需展开；看板或列表占据主工作区；任务详情作为覆盖式编辑层出现。

不采用以下方向：

- 只修改颜色和间距而保留现有空间分配，因为无法解决看板被挤压和移动端操作链过长的问题。
- 以移动端为唯一优先级重排全部结构，因为产品主要工作场景仍是桌面浏览器中的高密度任务整理。

## 桌面布局

```text
┌────────────┬────────────────────────────────────────────┐
│ 品牌与统计 │ 视图切换  搜索                  状态/详情 │
│ 快速添加   │ 状态  优先级  日期  项目  标签  完成开关 │
│ 备份操作   │                                            │
│            │  看板 / 列表占满剩余工作区                │
└────────────┴─────────────────────────────┬──────────────┘
                                           │ 任务详情抽屉 │
                                           └──────────────┘
```

- 左侧栏宽度约 `280px`，保持固定且不参与主内容横向滚动。
- 品牌区缩短垂直高度；四项统计改为单行紧凑指标，在侧栏窄宽度下保持稳定尺寸。
- 快速添加默认只显示标题输入、添加按钮和展开按钮。展开后显示备注、状态、优先级、日期、预计用时、精力、项目和标签。
- 导出与导入继续位于侧栏底部，不新增设置页或弹窗。
- 顶部工具栏拆为两行：第一行容纳视图切换、搜索、当前范围摘要和详情按钮；第二行是紧凑横向筛选条。
- 看板或列表使用主区域完整宽度。看板列保持稳定最小宽度并在主区域内部横向滚动，不让页面整体横向滚动。
- 详情面板宽度约 `360px`，从右侧覆盖主工作区；打开详情时看板宽度不重排。抽屉使用清晰边界与轻量阴影表示层级，但不使用玻璃拟态。

## 移动端布局

- 品牌与统计保持首屏可见，但统计仍为紧凑行，不占用四个大卡片高度。
- 快速添加默认折叠；展开时字段按单列排列。
- 视图切换采用 `2 × 2` 分段控制；搜索独占一行。
- 筛选区默认折叠为一个“筛选”按钮，同时显示已启用条件数量。展开后以单列控件显示。
- 看板按状态列纵向排列，不产生页面横向滚动。
- 详情面板在移动端使用全宽内容层，关闭后返回原工作位置。
- 所有触控控件保持至少 `40px` 高度，主要动作尽量达到 `44px`。

## 视觉系统

### 色彩

- `--surface-base: #f3f5f4`：中性工作区背景。
- `--surface-panel: #fbfcfa`：侧栏、工具条和抽屉表面。
- `--surface-raised: #ffffff`：任务卡、表单控件。
- `--ink: #18201d`：主要文字。
- `--muted: #59645f`：次级文字。
- `--accent: #155e63`：主要操作、当前视图和焦点。
- `--support: #526a88`：低频辅助信息，打破单一绿色倾向。
- `--warning: #b54a2f` 与 `--danger: #a33a32`：紧急和破坏性操作。

颜色不使用渐变、装饰色块或单一色系的大面积堆叠。强调色只服务于选中、操作、焦点和任务状态。

### 字体与密度

- 中文正文继续使用系统无衬线字体栈，保证本地加载和可读性。
- 统计数字使用系统等宽数字特性，强化快速比较，不引入运行时网络字体。
- 页面标题保持紧凑；卡片、工具栏和侧栏内部不使用大字号展示文案。
- 卡片圆角不超过 `8px`，阴影仅用于覆盖式详情抽屉。

### 标志性元素

本轮的视觉记忆点是“连续工作带”：视图、搜索、范围摘要和筛选形成两条安静、紧凑、对齐的操作带。它编码真实工作流，而不是装饰页面。

## 静态资源

- 功能控件继续统一使用现有 Lucide 图标，不混入第二套按钮图标。
- 从 unDraw 的开放授权插画中选择三张轻量 SVG，分别用于：今日任务已清空、暂无已完成任务、筛选无结果。
- 插画下载到 `src/assets/empty-states/` 并随构建发布，不在运行时请求外部 URL。
- 插画统一调整为中性灰、深青和辅助冷灰蓝，最大显示尺寸受空状态容器约束，不进入任务卡片或看板空列。
- 空状态文案已经完整表达含义时，插画使用空 `alt` 并设为装饰性；资源加载失败不影响操作按钮和说明文字。
- 在 `docs/third-party-assets.md` 记录资源名称、来源页面、下载日期和许可。

## 组件与状态边界

`TaskWorkspace` 继续拥有任务、筛选、视图、选择、导入、消息和拖拽状态。新增的纯界面状态也由它统一编排：

- `isQuickAddExpanded`：完整快速添加表单是否展开。
- `isMobileFiltersExpanded`：移动筛选区域是否展开。
- `showDetail`：继续控制详情面板，并改为抽屉展示语义。

现有组件职责调整：

- `TaskQuickAdd`：接收展开状态和切换回调，始终保留标题输入与添加动作。
- `TaskToolbar`：接收筛选展开状态、活动筛选数量和切换回调；桌面保持筛选常驻，移动端按需展开。
- `TaskDetailPanel`：保留编辑字段和回调，只改变容器层级与响应式呈现。
- `TaskViews`：保持任务卡、列表和拖拽接口不变，仅配合新的可用空间与空状态插画。

任务领域逻辑、备份格式、存储键和导入导出行为不修改。

## 交互细节

- `n` 快捷键在快速添加折叠时先展开表单，再聚焦标题输入；`/` 继续聚焦搜索。
- 点击任务时打开详情抽屉；关闭抽屉不清除当前任务选择。
- 桌面筛选条在中等宽度下允许容器内部横向滚动，筛选控件不撑满整行。
- 移动端筛选按钮显示活动筛选数量；清空筛选后数量归零，但展开状态不强制改变。
- 拖拽反馈、批量选择条和操作状态消息继续沿用现有行为与可访问状态区域。
- 尊重 `prefers-reduced-motion`；抽屉动画仅使用短距离位移与透明度变化，减少动态偏好下直接取消过渡。

## 错误与降级

- 静态插画无法加载时保留空状态文案和操作入口，不显示破损占位尺寸。
- 窄宽度下若筛选控件总宽度超出，滚动限制在筛选条内部。
- 详情抽屉打开时不修改任务数据；所有字段仍通过现有回调实时持久化。
- 不新增网络请求、异步业务状态或外部运行时依赖。

## 测试与验收

### 自动化测试

- 快速添加默认折叠，展开后完整字段可用。
- `n` 快捷键能够展开并聚焦标题输入。
- 移动筛选按钮能够展开/收起筛选控件，并正确显示活动筛选数量。
- 任务详情仍可打开、编辑和关闭，且关闭后任务保持选中。
- 现有创建、筛选、导入、导出、拖拽、批量操作和视图切换测试全部保持通过。
- CSS 回归测试覆盖桌面主栅格、筛选内部滚动、详情抽屉定位和移动端无页面横向溢出的关键选择器。

### 浏览器验收

使用 Playwright 检查以下视口：

- `1440 × 900`：侧栏、两行工作带、五列看板和详情抽屉层级正确。
- `1024 × 768`：筛选条内部滚动，主内容不被详情抽屉永久压缩。
- `390 × 844`：快速添加与筛选默认折叠，任务卡和详情不发生水平溢出。

每个视口检查页面截图、控制台错误、主要交互和文本是否溢出。允许的唯一非功能性网络错误为开发环境缺失 favicon；实现阶段应同时补充本地图标以消除该错误。

## 范围外

- 不增加账号、云同步、多人协作、日历视图或外部集成。
- 不改变任务模型和备份 JSON 格式。
- 不引入组件库、CSS 框架、动画框架或远程字体。
- 不重写现有领域逻辑或存储层。
