# 个人任务管理库

一个本地优先的个人任务管理工作台。当前版本使用 React、TypeScript、Vite 和 Vitest 构建，任务数据保存在浏览器 localStorage 中。

## 功能

- 创建、编辑、完成、重新打开、删除任务
- 批量选择任务，并支持批量完成、移动状态和删除
- 状态：收件箱、下一步、已安排、等待中、已完成
- 优先级、截止日期、预计用时、精力类型、项目、标签、备注
- 搜索与状态、优先级、日期、项目、标签筛选
- 按紧急程度和日期自动排序，已完成任务默认排在后面
- 可选隐藏已完成任务，保持工作视图清爽
- 按状态分组的看板式工作区
- 看板任务可拖到其他状态列，快速推进任务状态
- 同列任务可拖到其他任务前，手动顺序会保存到本地数据
- 未启用筛选时，可在每个看板列中输入标题并按 `Enter` 或加号快速新建任务
- 渐进式快速新增：标题和添加动作常驻，完整任务字段按需展开
- 桌面紧凑筛选工作带与移动端筛选展开面板
- 覆盖式任务详情抽屉，不再持续挤压看板和列表空间
- 本地打包的空状态插画，不依赖运行时外部资源
- 看板、列表、今日、已完成四种视图切换
- 今日视图会收纳今天到期和已经逾期的未完成任务
- 今日范围按浏览器本地日期计算，并在本地午夜、窗口重新聚焦或页面重新可见时自动刷新
- 空状态会区分筛选无结果、今日已清空、暂无已完成，并提供局部清空筛选入口
- 快捷键：`/` 聚焦搜索，`n` 聚焦新建任务，`1/2/3/4` 切换看板/列表/今日/已完成
- 导入 / 导出 JSON 任务备份
- 导入前预览任务数量，并支持替换或合并到当前任务
- 有效空备份也会进入确认流程，可将任务库明确替换为零个任务
- 连续选择多个导入文件时以后选文件为准，文件输入会重置以支持再次选择同一路径
- 合并导入时会跳过重复任务 id，避免覆盖已有任务
- 导入文件限制为 5 MiB 和 10,000 个任务，并校验字段长度、重复 id、日期、时间戳和未知字段
- 本地快照损坏时保留原始数据，可下载、重试读取或显式用当前任务重置
- 本地持久化，刷新后保留数据
- 任务领域逻辑、备份导入导出和存储适配器测试

## 当前边界

工作台渲染已拆分为更清晰的 UI 组件，任务状态仍由主工作台统一编排。替换导入、删除和批量操作会清理失效选择，避免遗留过期的批量状态。快速新增、移动筛选和详情抽屉的展开状态是临时 UI 状态，不包含在任务备份数据中。

当前版本不包含账号、云同步、多人协作和外部集成。看板已支持跨列拖放推进状态和同列手动排序，旧任务数据会自动补齐排序、预计用时和精力字段。多个浏览器标签页同时编辑时仍是最后写入覆盖，不会做冲突检测或合并。

导入不会立刻覆盖当前任务。选择“替换当前任务”会用导入文件覆盖现有数据；选择“合并到当前任务”会只加入新 id 的任务。空备份可被明确确认并替换为空任务库，后选文件完成读取前不会继续显示旧文件的确认操作。
